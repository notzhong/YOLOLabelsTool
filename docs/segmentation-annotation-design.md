# 分割标注功能设计（2.5.0）

> 状态：已实现（2026-10-18）
> 相关版本：v2.5.0
> 验证入口：`tools/verify_polygon_flow.py`（offscreen 全流程）、`tests/test_segmentation_guard.py`（静态守卫）

## 1. 背景与目标

原工具只支持矩形框（目标检测）标注。本次为标注链路引入**图像分割标注（多边形 / YOLO-seg）**，
目标是让同一套工具同时产出检测与分割两种 YOLO 数据集，且两种数据可互转：

1. **标注**：在画布上绘制与编辑多边形；
2. **显示**：多边形标注的渲染、选中、标签、统计；
3. **导出**：按任务模式导出 YOLO 检测框或 YOLO-seg 多边形格式；
4. **导入**：把已有的 YOLO 标签（.txt）导入当前图片或按文件夹批量匹配；
5. **转换**：框 ↔ 多边形互转（当前图片 / 整个文件夹）；
6. **模型辅助**：分割模型自动标注输出多边形，模型任务与模式不匹配时自动适配。

## 2. 范围

**做**：多边形（YOLO-seg）标注；多边形顶点编辑；检测/分割任务模式隔离；导入、导出、互转；
分割模型（`masks.xyn`）辅助标注。

**不做**：像素级掩膜（mask）标注/编辑；SAM 半自动点选；自由手绘（freehand）多边形。

选型理由：YOLO-seg 训练只需要多边形（归一化顶点序列），掩膜/点选的工作量显著更大而收益有限。

## 3. 交互设计

### 3.1 绘制（顶点逐点式，不用自由手绘）

| 操作 | 行为 |
|---|---|
| 左键单击空白处 | 追加一个顶点，跟随橡皮筋预览 |
| 双击 / 单击起点附近 / Enter | 闭合多边形（≥ 3 个顶点才允许） |
| Backspace / 绘制中右键 | 回退最后一个顶点 |
| Esc | 取消整个绘制 |

- 少于 3 个顶点闭合时给出状态栏提示 `polygon_min_points_hint`。
- 绘制状态下 `canvas.is_polygon_drawing()` 为真，窗口层 Ctrl+Z 会拦截为"回退顶点"
  （`polygon_undo_last_point()`），而不是撤销历史命令（见 §7）。

### 3.2 编辑（选中后）

| 操作 | 行为 |
|---|---|
| 单击 | 选中（`_deselect_all_except`） |
| 拖动顶点 | 移动单个顶点（命中阈值 16px，`_hit_vertex`） |
| 拖动多边形内部 | 整体平移 |
| 双击边附近 | 在边上插入一个顶点 |
| 右键顶点 | 删除顶点（剩余 ≤ 3 时拒绝并提示） |
| 右键多边形内部 | 弹出菜单：改类别 / 删除标注 |
| Delete | 删除选中标注 |

- 类别颜色、统计口径与矩形一致（统计按类合并计数）。
- 标签文本锚定到外接矩形左上角（`_sync_text_item`）。
- **文本标签与十字准线不接收鼠标**（`setAcceptedMouseButtons(Qt.NoButton)`）：
  纯装饰元素，否则会覆盖在标注项上方吞掉点击（2.5.0 修复的既有缺陷）。

## 4. 数据模型与存储

### 4.1 `PolygonAnnotation`（`src/core/annotation.py`）

```python
{"type": "polygon", "points": [[x, y], ...], "class_id": int}
```

- 像素坐标存储（与矩形一致）；导出时归一化（6 位小数）。
- 顶点数下限 3，创建/导入/导出三处都会校验。
- 与 `Annotation`（矩形）互转：
  - `PolygonAnnotation.from_box(box)`：矩形 → 4 顶点多边形；
  - `Annotation.from_polygon(polygon)`：多边形 → 外接矩形。
- 旧标注文件没有 `type` 字段，按"矩形"兼容解析（`annotation_from_dict`）。

### 4.2 YOLO-seg 标签格式

```
<class_id> <x1> <y1> <x2> <y2> ... <xn> <yn>     # 1 + 2k 字段，k ≥ 3
```

- 与检测格式（`class cx cy w h`，5 字段）靠字段数区分；
- `data.yaml` 仅分割任务写入 `task: segment`；
- 导入解析：5 字段 = 框；`1 + 2k`（k ≥ 3）= 多边形；其余行跳过并计数（日志 + 汇总提示）。

## 5. 任务模式（全局开关）

- 工具栏下拉框 `task_mode_combo`（`detect` / `segment`），持久化到 `config.ini [preferences] task_mode`。
- 切换任务模式会同步画布（`canvas.set_task_mode`），取消进行中的绘制。
- **模式只管绘制与导出格式，不改变存储**：同一条标注数据在两种模式下都能显示。
- 打开文件夹后若已有标注与当前模式不匹配（例如 segment 模式但全是框），状态栏提示，
  不阻塞操作（`hint_task_mode_mismatch`）。

## 6. 导入 / 转换 / 导出

### 6.1 导入（"YOLO 标签"菜单）

| 入口 | 行为 | 撤销 |
|---|---|---|
| 导入当前图片 | 选择 .txt → 解析（覆盖前确认）→ 记录跳过数 | **一步可撤销**（`EditAnnotationsCommand` + `push_command`） |
| 批量导入 | 选择文件夹 → 按文件名主干与图片匹配（覆盖确认 + 进度条 + 可取消） | 不可撤销，完成后清空撤销/重做栈 |

- 当前图片导入解析出 0 条有效行时：恢复导入前状态并警告（`import_nothing_parsed`），不产生空操作。
- 批量导入中 0 条解析的文件保留原标注不动。

### 6.2 框 ↔ 多边形互转

| 入口 | 行为 | 撤销 |
|---|---|---|
| 当前图片转分割/转检测 | 一次性转换全部标注 | 一步可撤销 |
| 文件夹批量转分割/转检测 | 确认（列出数量）→ 进度条 → 逐图落盘 | 不可撤销；完成后清空撤销/重做栈 |

### 6.3 导出

- `YoloExporter.export(..., task=...)`：按 `task` 输出对应格式，`data.yaml` 分割时写 `task: segment`。
- **导出前临时转换确认**（`confirm_export_conversion`）：存在与模式不匹配的标注时，
  列出数量并确认"临时转换"——只影响导出结果，**存储数据不变**。
- 未标注图片仍生成空 `.txt`，保证 images/labels 一一对应。

### 6.4 模型辅助标注

- `ModelManager` 识别模型任务（`model_task`），分割模型推理结果从 `result.masks.xyn` 提取多边形。
- 自动标注按 `task=self.task_mode` 转换：
  - segment 模式 + 检测模型 → 框转 4 点多边形；
  - detect 模式 + 分割模型 → 掩码取外接矩形（框）。
- 模型任务与当前模式不一致时，状态栏给出适配提示（`auto_convert_*_hint`），不弹窗阻断。

## 7. 撤销/重做策略（关键实现细节）

### 7.1 编辑手势 = 一步撤销（保留对象身份）

拖动顶点/平移/插删顶点等都是"原地修改画布上的对象"。若沿用命令模式
（执行命令 → 重新加载画布），会在事件派发中途删除图形项，引发 Qt 崩溃。
最终方案：

1. 图形项按下时 `canvas._begin_edit_capture()` → `edit_gesture_started`：
   窗口层对当前标注列表做**深拷贝快照**；
2. 释放时 `canvas._end_edit_capture()` → `edit_gesture_finished`：
   - `save_annotations(path, canvas.get_annotation_items())` 把**当前活对象**写回缓存
     （画布与缓存保持同一批对象，删除/改类的 identity 查找不受影响）；
   - 构造 `EditAnnotationsCommand(manager, path, old_state, new_state)`（构造时各自深拷贝）
     并调用 **`push_command()`**（命令已生效，只入栈）而不是 `execute_command()`；
   - 新旧状态相同则跳过（例如单击未拖动）。

### 7.2 其他规则

- 矩形移动/缩放的撤销语义维持原状（不在本次手势化范围内）。
- 绘制过程中 Ctrl+Z = 回退顶点（窗口 `undo()` 先查 `canvas.is_polygon_drawing()`）；
  绘制中 `redo()` 不动作。
- 批量操作（文件夹导入/转换）**不是用户手势**，完成后直接清空撤销/重做栈，
  避免栈中命令指向过期状态。
- 撤销栈上限沿用 `MAX_UNDO_SIZE = 100`；`push_command` 入栈时清空重做栈（与执行命令一致）。

## 10. 已知取舍

- 多边形不支持顶点吸附/吸附到图像边界；
- 双击边插点是"最近边"插值，不做精确的投影点命中优化；
- 批量转换不做逐图撤销（只提供操作前确认 + 进度显示）；
- 导入只解析当前类别 ID 空间，不做类别名映射（与 YOLO 标签语义一致）；
- 遗留的历史缺口：`Yes/No`（仅 zh）、`image_name_label`（仅 en）等旧 key 的双侧差异不在本次范围内。
